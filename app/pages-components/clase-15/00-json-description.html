Que hace este ejercicio

Este ejercicio usa un objeto JSON con información de una bebida y recorre sus propiedades con jQuery para mostrar datos estructurados dentro de la página.

Objetivo: comprender como recorrer datos JSON y representarlos en el DOM con jQuery.

El nombre de la bebida y su inicio de producción se insertan en el DOM con text().

El array de ingredientes se transforma en elementos <li> y se añade dinámicamente a la lista.

Las marcas del JSON se recorren para construir filas de tabla con nombre, tipo y procedencia.
