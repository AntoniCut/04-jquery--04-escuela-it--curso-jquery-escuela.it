Que hace este ejercicio

Usa data() y removeData() para guardar y eliminar datos asociados a elementos del DOM, y acumular clics sin variables externas.

Objetivo: gestionar estado ligado a elementos con data() y removeData().

Haz click en cada tarjeta para acumular clics con data().

Al llegar a 10 clics se usa removeData().

El select de playground permite resetear contadores e info.
