Que hace este ejercicio

Usa los helpers nativos de Handlebars: #if / else para campos opcionales y #each para listar personas y rellenar un select.

Objetivo: controlar flujo y repeticion sin escribir helpers propios.

{{#if title}} pinta el valor o un fallback si el input esta vacio.

{{#each people}} recorre el array ordenado por apellido y nombre.

El tercer panel genera un select con una option por persona.
