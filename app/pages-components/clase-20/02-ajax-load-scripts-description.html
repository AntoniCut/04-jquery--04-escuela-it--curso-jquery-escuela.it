Que hace este ejercicio

Muestra como cargar y ejecutar un archivo JavaScript remoto mediante $.ajax() con dataType: "script". El script descargado actualiza el contenido de la pagina al ejecutarse.

Objetivo: Comprender la carga dinamica de scripts con la API de bajo nivel de Ajax en jQuery.

El click solicita script.js al servidor.

jQuery interpreta la respuesta como script y la ejecuta automaticamente.

El script remoto escribe el mensaje en #respuesta.
