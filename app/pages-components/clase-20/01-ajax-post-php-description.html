Que hace este ejercicio

Demuestra una peticion Ajax de bajo nivel con $.ajax() usando el metodo POST. Al hacer click en la capa se envia un dato al servidor PHP y la respuesta HTML se inserta en el contenedor de salida.

Objetivo: Aprender a configurar $.ajax() con url, type, data, dataType y el callback success.

El click en la capa dispara la peticion POST sin recargar la pagina.

Se envia el objeto { dato: "valor" } al endpoint PHP.

La respuesta del servidor se renderiza dentro de #respuesta.
