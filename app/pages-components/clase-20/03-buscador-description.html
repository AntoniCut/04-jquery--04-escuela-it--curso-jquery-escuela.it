Que hace este ejercicio

Implementa un buscador de productos con formulario. Al enviar, se evita el submit clasico y se serializan los campos con serialize() para enviarlos por POST con $.ajax().

Objetivo: Combinar formularios, serializacion y Ajax de bajo nivel para consultar productos (base classicmodels).

preventDefault() evita la recarga de la pagina al enviar.

Los campos se envian con $(this).serialize().

El servidor responde con una tabla HTML de resultados.
