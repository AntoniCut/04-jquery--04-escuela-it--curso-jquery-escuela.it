Que hace este ejercicio

Profundiza en la introduccion a jQuery: como funciona internamente, como se incluye correctamente y cuales son sus conceptos clave antes de empezar a usarlo.

Objetivo: comprender la estructura basica de un script con jQuery y estar listo para trabajar con el DOM.

La funcion $() es el punto de entrada a toda la API de jQuery.

Usa $(document).ready() o su forma abreviada $(function(){}).

Incluye jQuery desde CDN o como archivo local en el proyecto.
