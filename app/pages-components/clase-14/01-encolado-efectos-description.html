Que hace este ejercicio

Este ejercicio encadena varios efectos sobre el mismo elemento usando la cola fx de jQuery, y actualiza el texto antes de cada paso para indicar que animacion se esta ejecutando.

Objetivo: comprender como funciona el encolado secuencial de efectos y como interrumpirlo de forma controlada.

Al pulsar Animar se encolan slideUp(), slideDown(), fadeOut(), fadeIn() y cambios de tamaño con animate().

Cada mensaje se inserta con queue() para que aparezca justo antes del efecto correspondiente, mientras el parrafo se anima en paralelo.

Si haces click sobre el texto se usa finish('fx') para completar la cola pendiente y dejar el elemento en su estado final.
