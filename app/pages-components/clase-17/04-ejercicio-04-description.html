Que hace este ejercicio

Tienes un menú inicialmente oculto. Solo ves un pequeño control con un icono, enlace o algo parecido. Al pulsar el icono se despliega el menú. El menú se oculta nuevamente pasados 3 segundos. Hacer el ejercicio de 2 formas distintas: 1. Usando los métodos de efectos de jQuery y el método delay(). 2. Usando la función setTimeout() de JavaScript.

Objetivo: comparar el auto-ocultado de un menú con delay() de jQuery frente a setTimeout() de JavaScript.

Al pulsar el control se muestra el menú correspondiente.

Tras 3 segundos el menú se oculta de nuevo automáticamente.

La forma 1 usa efectos jQuery + delay(); la forma 2 usa setTimeout().
