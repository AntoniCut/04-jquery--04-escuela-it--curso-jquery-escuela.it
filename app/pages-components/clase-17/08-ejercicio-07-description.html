Que hace este ejercicio

Continuar el ejemplo del menú contextual Clase 12 - 2. Menú Contextual Personalizado para controlar el auto-ocultado según la interacción del ratón con el menú.

Objetivo: evitar que el menú contextual se oculte mientras el ratón está encima y reprogramar el cierre al salir.

El menú se oculta automáticamente pasados dos segundos.

Si el usuario pone el ratón encima del menú, el menú no debe ocultarse.

Cuando el usuario sale del menú con el ratón, el menú debe ocultarse pasados dos segundos.
