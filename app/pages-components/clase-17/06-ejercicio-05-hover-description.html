Que hace este ejercicio

Tienes una lista de imágenes. Las imágenes tienen atributo "alt", con texto alternativo. Quieres crear pies de foto para cada una de las imágenes. El texto alternativo debe aparecer al hacer hover sobre la imagen, como un pie de foto. El pie de foto debe aparecer debajo de cada imagen. El texto del pie de foto debe de ser el mismo que hay en el alt, el suyo de cada imagen. Haz un tratamiento por si la imagen no tiene atributo alt. En ese caso se debe mostrar un pie de foto con un texto genérico, por ejemplo "copyright 2014". Esta es una alternativa de solución al ejercicio 05 utilizando los eventos mouseenter y mouseleave.

Objetivo: mostrar y ocultar el pie de foto con mouseenter / mouseleave a partir del atributo alt.

Al pasar el ratón por una imagen aparece su pie de foto debajo.

Al salir el ratón, el pie de foto se oculta.

Si la imagen no tiene alt, se usa un texto genérico de copyright.
