Que hace este ejercicio

Este ejercicio amplía la animacion anterior usando el objeto de opciones de animate() para configurar duracion, easing, paso a paso y accion final.

Objetivo: dominar la configuracion avanzada de animate para crear animaciones mas controladas y expresivas.

Se usa duration para controlar el tiempo total y easing para la curva global.

Con specialEasing se aplica la misma curva a cada propiedad animada de forma explicita.

El callback step actualiza el texto en tiempo real y complete restaura estilos al finalizar.
