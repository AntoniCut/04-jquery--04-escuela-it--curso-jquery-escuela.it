Que hace este ejercicio

Amplia el login modal con autenticacion real contra MySQL (jquery_escuelait_classicmodels.login_users). El usuario puede registrarse o iniciar sesion; si intenta entrar sin estar dado de alta, se le indica que debe registrarse.

Objetivo: combinar Ajax + JSON con consultas mysqli (SELECT / INSERT) y contraseñas hasheadas con password_hash / password_verify.

Registro: inserta usuario y clave (hash) en login_users.

Login: consulta la BD; si no existe, pide registrarse.

Login correcto: entra a la zona privada sin recargar la pagina.
