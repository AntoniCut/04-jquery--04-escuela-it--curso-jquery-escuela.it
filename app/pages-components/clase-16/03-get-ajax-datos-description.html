Que hace este ejercicio

Este ejercicio amplía $.get() enviando datos al servidor (nombre y apellido) y utiliza los Global Ajax Event Handlers de jQuery para registrar en tiempo real cada fase del ciclo de vida de la petición.

Objetivo: comprender cómo enviar datos con $.get() y cómo los Global Ajax Event Handlers permiten observar el ciclo completo de cualquier petición AJAX en la página.

Se pasa un objeto myJSON como segundo argumento de $.get(); jQuery lo serializa como parámetros GET.

Los manejadores globales ajaxStart, ajaxSend, ajaxSuccess, ajaxError y ajaxComplete registran entradas en el log.

El indicador de carga aparece al iniciar la petición y desaparece al completarse.
