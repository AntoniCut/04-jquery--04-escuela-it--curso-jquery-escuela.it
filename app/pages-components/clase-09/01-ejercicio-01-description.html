Que hace este ejercicio

Practica recorrer elementos con each() y usar this / el indice para asignar contenido dinamico a cada parrafo vacio del DOM.

Objetivo: practicar each() e index para iterar y numerar contenido.

Se seleccionan todos los parrafos dentro de .contenido.

Con each() se inserta el texto Elemento N segun la posicion.

Los indices pares se colorean en rojo para reforzar el uso del index.
