Clase 16 - 2. Get AJAX

Que hace este ejercicio

Este ejercicio usa el método $.get() de jQuery para hacer una petición AJAX GET a un archivo PHP y mostrar el contenido recibido en el área de resultado.

  • Al hacer clic en el enlace se lanza $.get(url, callback); la respuesta llega como texto HTML que se parsea creando un elemento div temporal.
  • Se extrae el <h3> del HTML parseado con .find('h3') y se inserta en #salida usando .empty().append() para no acumular respuestas anteriores.
  • A diferencia de .load(), $.get() es un método global de jQuery que ofrece control total sobre la respuesta antes de insertarla en el DOM.

Objetivo: entender el uso básico de $.get() con su callback de éxito, y cómo parsear una respuesta HTML para extraer solo el fragmento que interesa antes de mostrarlo.
