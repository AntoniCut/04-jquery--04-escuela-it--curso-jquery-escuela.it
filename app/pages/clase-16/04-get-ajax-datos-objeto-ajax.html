Clase 16 - 4. Get AJAX Datos Objeto AJAX

Que hace este ejercicio

Este ejercicio replica la funcionalidad del ejercicio 3 pero sustituye el callback de $.get() por los Deferred Methods: .done(), .fail() y .always(), combinándolos con los Global Ajax Event Handlers.

  • $.get() devuelve un objeto jqXHR; sobre él se encadenan .done() para manejar el éxito, .fail() para los errores y .always() para la lógica que debe ejecutarse siempre.
  • Los Deferred Methods son locales a la petición, mientras que los Global Ajax Event Handlers (ajaxStart, ajaxSend…) reaccionan a cualquier petición AJAX activa en la página, complementándose entre sí.
  • El overlay de carga incluye además un <img> GIF animado junto al spinner CSS, y todos los eventos quedan registrados en el panel de log lateral.

Objetivo: entender la diferencia entre los Deferred Methods (ámbito local de una petición) y los Global Ajax Event Handlers (ámbito global del documento), y saber cuándo usar cada patrón.
