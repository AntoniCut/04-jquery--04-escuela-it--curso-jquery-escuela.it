Ejercicio 1 - Rellenar parrafos numerados

Este ejercicio practica recorrer elementos con each() y usar this para asignar contenido a cada parrafo del DOM.

  • Se seleccionan todos los parrafos dentro del contenedor.
  • Con each() se itera cada parrafo y se inserta el texto "parrafo N" usando la posicion.
  • Se practica el index en each() para generar contenido dinamico basado en la posicion.

Objetivo: practicar each() e index para iterar y numerar contenido.
