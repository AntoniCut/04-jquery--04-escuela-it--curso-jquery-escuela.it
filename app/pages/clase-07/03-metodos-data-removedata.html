Clase 7 - 3. Métodos data() y removeData()

Metodos data() y removeData()

Este ejercicio usa data() y removeData() para almacenar y eliminar datos personalizados asociados a elementos del DOM.

  • data() lee o guarda informacion en un elemento usando atributos data-*.
  • removeData() elimina un dato previamente almacenado sin afectar al HTML.
  • Es util para asociar estado o configuracion a un elemento sin usar variables externas.

Objetivo: gestionar datos ligados a elementos del DOM de forma limpia con data() y removeData().
