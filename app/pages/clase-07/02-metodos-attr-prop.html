Metodos attr() y prop()

Este ejercicio trabaja con attr() y prop() para leer y modificar atributos y propiedades de elementos del DOM con jQuery.

  • attr() accede a atributos HTML como action, placeholder o class.
  • prop() accede a propiedades del DOM como checked o disabled.
  • Se usa un formulario real para practicar la lectura y escritura dinamica de ambos.

Objetivo: distinguir entre atributos y propiedades del DOM y saber cual usar en cada caso.
