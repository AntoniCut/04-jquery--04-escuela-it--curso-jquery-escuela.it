Clase 7 - 1. Métodos html() y text()

Metodos html() y text()

Este ejercicio compara los metodos html() y text() de jQuery para leer y escribir contenido en elementos del DOM.

  • html() lee o escribe contenido incluyendo etiquetas HTML.
  • text() lee o escribe contenido solo como texto plano, sin interpretar HTML.
  • Comparar ambos permite entender cuando usar uno u otro segun el caso de uso.

Objetivo: dominar la lectura y escritura de contenido en el DOM con html() y text().

En esta práctica vamos a aprender a usar los métodos .html() y .text() de jQuery para manipular el contenido de los elementos HTML.

Este contenido se renderizará dentro del elemento con el id #outputHtml utilizando ambos métodos, para que puedas comparar los resultados y entender las diferencias entre ellos.
