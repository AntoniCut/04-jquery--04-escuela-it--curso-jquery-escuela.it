Metodo each() para recorrer elementos

Este ejercicio usa el metodo each() de jQuery para iterar sobre una coleccion de elementos y aplicar logica a cada uno de forma individual.

  • each() recorre cada elemento del conjunto seleccionado y ejecuta un callback.
  • Dentro del callback, $(this) referencia el elemento actual de la iteracion.
  • Se diferencia entre elementos con y sin clase para mostrar el comportamiento selectivo.

Objetivo: dominar each() como herramienta fundamental para operar sobre multiples elementos.
