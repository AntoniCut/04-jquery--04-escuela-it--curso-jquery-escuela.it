Clase 5 - Introducción a jQuery

Introduccion a jQuery

Este modulo profundiza en la introduccion a jQuery: como funciona internamente, como se incluye correctamente y cuales son sus conceptos clave antes de empezar a usarlo.

  • Se explica la funcion $() como punto de entrada a toda la API de jQuery.
  • Se revisa el uso de $(document).ready() y su forma abreviada $(function(){}).
  • Se descarga e incluye jQuery desde CDN y como archivo local en el proyecto.

Objetivo: comprender la estructura basica de un script con jQuery y estar listo para trabajar con el DOM.
