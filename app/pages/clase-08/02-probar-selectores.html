Probando selectores en jQuery

Este ejercicio es una herramienta interactiva para probar selectores de jQuery en vivo y ver el resultado al momento, aplicando estilos CSS dinamicamente.

  • Escribes un selector en un input y se aplica a los elementos que coinciden.
  • Se usan inputs de color para cambiar el fondo y el texto con css().
  • Permite experimentar con selectores sin escribír código, aprendiendo por exploración.

Objetivo: practicar selectores de forma interactiva y entender como afectan el metodo css() de jQuery.
