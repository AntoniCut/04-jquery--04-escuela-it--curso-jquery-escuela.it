Que es jQuery

Este modulo introduce jQuery, la libreria JavaScript mas usada para simplificar la manipulacion del DOM, el manejo de eventos y las peticiones AJAX.

  • jQuery es una libreria, no un framework: se include en el proyecto y te da utilidades listas para usar.
  • Abstrae diferencias entre navegadores y reduce el codigo necesario para trabajar con el DOM.
  • Permite hacer peticiones AJAX, animar elementos y gestionar plugins de forma sencilla.

Objetivo: entender que es jQuery, por que se usa y en que situaciones sigue siendo util hoy en dia.
