Clase 6 - Primeros Pasos con jQuery - Ejemplo 1

Seleccionar elementos y ocultar / mostrar

Este ejercicio muestra como seleccionar elementos del DOM con jQuery y controlar su visibilidad con hide() y show().

  • Se seleccionan elementos por id y por clase con la funcion $().
  • hide() oculta el elemento y show() lo vuelve a mostrar.
  • Un boton run dispara la accion para ver el efecto en tiempo real.

Objetivo: practicar selectores basicos de jQuery y los metodos de visibilidad hide() y show().
