Clase 17 - Ejercicio 05 Alternativa 1

Que hace este ejercicio

Tienes una lista de imágenes. Las imágenes tienen atributo "alt", con texto alternativo. Quieres crear pies de foto para cada una de las imágenes. El texto del pie de foto debe de ser el mismo que hay en el alt, el suyo de cada imagen. Haz un tratamiento por si la imagen no tiene atributo alt. En ese caso se debe mostrar un pie de foto con un texto genérico, por ejemplo "copyright 2014".

Esta es una alternativa de solución 1 al ejercicio 05.
