Recorrer elementos con each()

Este ejercicio usa el metodo each() de jQuery para recorrer multiples elementos del DOM y procesar cada uno individualmente.

  • Se seleccionan parrafos por clase y elementos de una lista por id.
  • each() itera sobre cada elemento seleccionado y ejecuta una funcion por cada uno.
  • Se muestra el contenido de cada elemento usando $(this) dentro del callback.

Objetivo: dominar el metodo each() para iterar colecciones de elementos con jQuery.
