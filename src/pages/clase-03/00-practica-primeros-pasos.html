Clase 3 - Práctica Primeros Pasos con jQuery

Primeros pasos con jQuery

Este modulo pone en practica los conceptos basicos de jQuery: como incluirlo en un proyecto y escribir el primer codigo funcional.

  • Se aprende a descargar e incluir jQuery via CDN o archivo local.
  • Se usa $(document).ready() para ejecutar codigo cuando el DOM esta listo.
  • Se realizan las primeras selecciones y manipulaciones de elementos del DOM con jQuery.

Objetivo: configurar jQuery en un proyecto y escribir los primeros selectores y acciones sobre el DOM.
