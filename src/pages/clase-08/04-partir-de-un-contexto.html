Clase 8 - 4. Partir de un Contexto

En esta sección vamos a ver como partir de un contexto para seleccionar elementos, esto es útil cuando queremos seleccionar elementos dentro de un contenedor específico.

Para esto vamos a usar el segundo parámetro del selector de jQuery, este parámetro nos permite especificar el contexto en el que queremos buscar los elementos, también podemos usar el método .find() para buscar elementos dentro de un contexto específico.
