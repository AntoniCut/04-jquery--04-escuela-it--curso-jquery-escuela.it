Clase 14 - 4. Encolar funciones no efectos

Que hace este ejercicio

Este ejercicio mezcla efectos de jQuery con funciones normales dentro de la misma cola para modificar estilos entre animaciones.

  • Se encadenan slideUp(), slideDown() y varios animate() sobre el mismo bloque.
  • Entre medias se insertan funciones con queue() que cambian color y fondo aunque no sean efectos visuales propios de jQuery.
  • Una de esas funciones usa dequeue() de forma explicita y otra usa next() para liberar la siguiente tarea de la cola.

Objetivo: aprender a encolar funciones arbitrarias junto a efectos y controlar exactamente cuando continua la cola.
