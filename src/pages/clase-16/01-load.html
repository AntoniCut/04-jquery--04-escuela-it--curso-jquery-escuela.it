Clase 16 - 1. Load

Que hace este ejercicio

Este ejercicio usa el método .load() de jQuery para hacer una petición AJAX a un archivo PHP e inyectar el HTML devuelto directamente dentro de un elemento del DOM.

  • Al pulsar el botón se llama a $salida.load(url, callback), que realiza una petición GET al servidor y vuelca la respuesta HTML dentro de #salida.
  • El segundo argumento de .load() es un callback que se ejecuta cuando la carga finaliza, en este caso lanza un alert de confirmación.
  • A diferencia de $.get(), .load() es un método de instancia: actúa directamente sobre el elemento jQuery seleccionado sin necesidad de manipular la respuesta manualmente.

Objetivo: comprender cómo .load() combina la petición AJAX y la inserción del contenido en una sola llamada, simplificando el código cuando solo se necesita volcar HTML remoto en un elemento.
