Clase 24 - Template Systems

Que hace esta clase

Esta pagina resume los ejercicios de la clase 24: como generar HTML a partir de plantillas con Handlebars y, en contraste, como montar el mismo resultado creando nodos con jQuery.

  • 01 Compilar un string fijo con Handlebars.compile y pintar el HTML resultante.
  • 02 Template como string en JavaScript con placeholders {{title}} y {{body}}.
  • 03 Template declarado en un script type="text/x-handlebars-template".
  • 04 Misma salida sin motor de plantillas: crear el DOM con $(), .text() y .append().
  • 05 Cargar un template externo por AJAX con $.get.
  • 06 Helpers de bloque personalizados (toH1, toUl).
  • 07 Paths anidados: {{author.id}} y {{author.name}}.
  • 08 Helpers nativos #if y #each.

Objetivo: separar datos y markup con un template system, y saber cuando basta con generar el DOM a mano.
