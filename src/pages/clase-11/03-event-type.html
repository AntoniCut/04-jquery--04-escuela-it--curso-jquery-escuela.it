Clase 11 - 3. Event Type

Event Type - Identificar tipo de evento

El objeto evento contiene propiedades que identifican el tipo de evento y su contexto, permitiendo tomar decisiones dentro de manejadores multiproposito La propiedad e.type devuelve el nombre del evento como string.

  • e.type retorna el nombre del evento: 'click', 'keydown', 'mouseover', etc.
  • Se puede usar para manejadores multiproposito que detectan multiples eventos.
  • Ejemplos: if (e.type === 'click') { ... } dentro de un manejador.

Objetivo: acceder a propiedades del evento para responder dinamicamente segun su tipo.
