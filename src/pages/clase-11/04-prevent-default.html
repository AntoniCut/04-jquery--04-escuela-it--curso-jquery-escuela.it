Clase 11 - 4. Prevent Default

preventDefault() - Cancelar comportamiento por defecto

preventDefault() cancela la accion predeterminada del navegador para un evento, permitiendo implementar comportamiento personalizado.

  • Links no navegan: $(enlace).on('click', (e) => e.preventDefault()).
  • Formularios no se envian: $(form).on('submit', (e) => e.preventDefault()).
  • Se usa combinado con logica personalizada: validacion, envios AJAX, etc.

Objetivo: interceptar acciones del navegador e implementar comportamiento personalizado.
