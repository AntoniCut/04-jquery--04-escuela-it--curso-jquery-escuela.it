Clase 10 - 5. Dimensiones

En esta sección se explicarán los métodos relacionados con las dimensiones de los elementos, como width, height, innerWidth, innerHeight, outerWidth y outerHeight.

Width : Devuelve el ancho del elemento, excluyendo el padding, border y margin.

Height : Devuelve la altura del elemento, excluyendo el padding, border y margin.

InnerWidth : Devuelve el ancho del elemento, incluyendo el padding pero excluyendo el border y margin.

InnerHeight : Devuelve la altura del elemento, incluyendo el padding pero excluyendo el border y margin.

OuterWidth : Devuelve el ancho del elemento, incluyendo el padding y el border. Si se pasa true como argumento, también incluirá el margin.

OuterHeight : Devuelve la altura del elemento, incluyendo el padding y el border. Si se pasa true como argumento, también incluirá el margin.
