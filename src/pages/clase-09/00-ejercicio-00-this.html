El concepto de this en jQuery

Este ejercicio pone en practica el concepto de this, que es fundamental para trabajar con eventos y manipular el elemento sobre el cual se dispara una accion.

  • this dentro de un evento se refiere al elemento que disparo el evento.
  • $(this) convierte ese elemento al objeto jQuery para manipularlo con metodos de jQuery.
  • Es el contexto actual: entender this permite escribir codigo reutilizable y senalizar el elemento correcto.

Objetivo: dominar this en jQuery para manejar eventos de forma precisa y eficiente.
