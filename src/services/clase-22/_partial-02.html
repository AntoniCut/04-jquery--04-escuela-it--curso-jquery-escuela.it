Contenido recogido de _partial-02

Este segundo fragmento sirve para practicar $.when(): jQuery espera a que terminen una o varias promesas y entonces dispara un unico .done() (o .fail() si alguna se rechaza).

Con varias peticiones, cada argumento del .done() corresponde a una de ellas:

  • $.when($.get(...)) envuelve una sola peticion
  • $.when(get1, get2) espera a las dos en paralelo
  • el HTML de cada partial llega como primer valor de cada retorno
  • .then(exito, fallo) separa el camino correcto del error

Si una de las URLs no existe, $.when() se rechaza y puedes mostrar el error en el contenedor sin anidar callbacks.
