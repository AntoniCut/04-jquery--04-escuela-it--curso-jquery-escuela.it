Que hace este ejercicio

El template no esta en la pagina: se pide por AJAX a services/clase-24/external-template.html con $.get y, cuando llega, se compila y se pinta.

Objetivo: reutilizar plantillas externas y combinarlas con datos del formulario.

$.get(url, callback, "text") trae el source como texto plano.

La compilacion ocurre en el callback, no antes de tener el template.

Si la peticion falla, el error se muestra en el preview, no en un alert.
