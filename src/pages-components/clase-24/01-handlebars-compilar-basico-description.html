Que hace este ejercicio

Compila un template Handlebars escrito como string fijo (<h1> Template </h1>) y pinta el HTML generado en la zona de preview y en el textarea.

Objetivo: entender el ciclo compile → context → template(context).

Handlebars.compile(source) convierte el string en una funcion de plantilla.

El contexto va vacio porque este template no usa placeholders.

El resultado se muestra dos veces: renderizado en el preview y como codigo en el textarea.
