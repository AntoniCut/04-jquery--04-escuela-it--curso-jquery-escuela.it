Que hace este ejercicio

Replica el mismo resultado que Handlebars, pero sin motor de plantillas: crea div, h1 y p con jQuery y los ensambla con .append().

Objetivo: contrastar un template system con generacion manual del DOM.

$('<h1>').text(title) inserta texto escapado, sin interpretar HTML.

El markup final se obtiene con .prop('outerHTML') para mostrarlo en el textarea.

No se carga Handlebars: este ejercicio es el contrapunto de los anteriores.
