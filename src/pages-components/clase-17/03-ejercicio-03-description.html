Que hace este ejercicio

Tienes una página con una serie de párrafos. Queremos que cada párrafo tenga debajo un Horizontal Rule (HR), para que esté separado del siguiente. Menos el último párrafo al que no le queremos colocar nada debajo.

Objetivo: practicar selectores y métodos de inserción para añadir HR entre párrafos, excluyendo el último.

Se seleccionan todos los párrafos menos el último.

Tras cada párrafo seleccionado se inserta un <hr>.

El último párrafo queda sin separador debajo.
