Que hace este ejercicio

En un formulario tienes un campo checkbox. Al pulsarlo debes desactivar con el método .prop("checked") de jQuery todos los textarea, y los input type text. Pero dejar activos todos los otros tipos de input.

Objetivo: usar .prop() para habilitar/deshabilitar campos concretos del formulario según el estado del checkbox.

Al marcar el checkbox se desactivan los textarea e input[type=text].

El resto de inputs (radio, select, etc.) siguen activos.

Al desmarcar el checkbox, los campos vuelven a quedar habilitados.
