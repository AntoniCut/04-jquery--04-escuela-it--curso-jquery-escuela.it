Metodo on() - Delegacion de eventos

on() es el metodo moderno para asignar manejadores de eventos, soportando delegacion que permite manejar elementos creados dinamicamente.

Objetivo: dominar on() para asignar eventos y delegarlos dinamicamente a elementos futuros.

Se asigna un evento a un selector: $(elemento).on('click', handler).

La delegacion permite: $(contenedor).on('click', '.selector', handler) para elementos futuros.

Compatible con todos los eventos: click, mouseover, keydown, change, submit, etc.
