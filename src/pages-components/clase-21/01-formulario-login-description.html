Que hace este ejercicio

Implementa un login modal con Ajax: al pulsar Hacer login aparece una caja centrada con fundido, se envian usuario y clave por POST y el servidor responde con un JSON que indica si el acceso es valido.

Objetivo: practicar efectos (fadeIn), posicionamiento absoluto, $.ajax() con dataType: "json" y feedback visual de error o exito.

El enlace abre una capa modal con overlay y la caja de login centrada.

Mientras espera la respuesta se muestra estado de carga y se deshabilita el submit.

Si el login es valido se entra a la zona privada; si no, el mensaje aparece en rojo.
