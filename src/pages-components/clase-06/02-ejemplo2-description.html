Que hace este ejercicio

Usa el metodo each() de jQuery para recorrer multiples elementos del DOM y procesar cada uno individualmente con $(this).

Objetivo: dominar each() para iterar colecciones de elementos con jQuery.

Selecciona parrafos por clase y elementos de lista por id.

each() ejecuta una funcion callback por cada elemento seleccionado.

Dentro del callback usas $(this) y puedes eliminar elementos con remove().
