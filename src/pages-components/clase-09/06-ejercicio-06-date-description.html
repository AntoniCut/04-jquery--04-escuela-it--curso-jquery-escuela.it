Que hace este ejercicio

Introduce el objeto Date de JavaScript para guardar timestamps y calcular el tiempo transcurrido entre clics en cada parrafo, almacenando el ultimo instante con data().

Objetivo: practicar Date, timestamps y guardar datos en elementos con data().

Se usa new Date().getTime() para obtener el timestamp actual en milisegundos.

El primer clic muestra segundos desde la carga; los siguientes, desde el ultimo clic en ese parrafo.

El resultado se escribe en #result y el tiempo se guarda con .data('time').
