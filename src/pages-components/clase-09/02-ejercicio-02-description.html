Que hace este ejercicio

Combina un array de colores RGB con each() para aplicar colores de fondo a cada li segun su posicion en el array.

Objetivo: integrar arrays de datos con iteracion en jQuery para estilos dinamicos.

Se declara un array con colores RGB y se itera cada li.

Para cada elemento se obtiene el color segun el index y se asigna con css().

Se practica acceso a array, iteracion y manipulacion dinamica de estilos.
