Que hace este ejercicio

Implementa selects dependientes (pais → provincia). Al cambiar el pais se lanza una peticion GET con dataType: "json" y se rellenan las opciones del segundo select con la respuesta.

Objetivo: Usar el ciclo completo de $.ajax() (beforeSend, success, complete, error y cache: false.

beforeSend muestra un estado de carga en el select de provincias.

La respuesta JSON se recorre para crear opciones dinamicas.

error y complete registran el estado de la peticion.
