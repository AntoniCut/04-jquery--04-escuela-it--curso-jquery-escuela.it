Que hace este ejercicio

Este ejercicio toma valores de un formulario y aplica una animacion personalizada con animate() sobre la propia caja del formulario.

Objetivo: entender como encadenar animaciones y transiciones en jQuery a partir de datos dinamicos.

Se capturan los datos de font-size, width y padding desde inputs.

Se ejecuta una secuencia de efectos: animate(), luego fadeOut() y despues fadeIn().

Al final se restauran valores base para reiniciar el componente y repetir la practica.
