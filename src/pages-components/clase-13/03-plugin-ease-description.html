Que hace este ejercicio

Este ejercicio integra el plugin jQuery Easing para cambiar la curva de aceleracion de una animacion y comparar distintos comportamientos visuales.

Objetivo: aprender a aplicar curvas de easing personalizadas para mejorar la sensacion de movimiento.

Se selecciona un tipo de easing desde el select (por ejemplo, linear o easeOutBounce).

Se anima la capa modificando width y height usando el easing elegido.

Al terminar, se restauran los estilos iniciales y se deja el componente listo para otra prueba.
