Que hace este ejercicio

Muestra dos formas de pasar datos a un manejador de eventos: como segundo parametro de on() o guardandolos antes con .data().

Objetivo: Aprender a pasar datos personalizados a manejadores de eventos usando el segundo parametro de on() o almacenandolos previamente con .data().

Los elementos 1 y 2 reciben parametros en on('click', { ... }, saludar).

Los elementos 3 y 4 guardan datos con .data('saludo', { ... }) y los leen en el manejador.

El registro indica que metodo se uso y el saludo generado.
